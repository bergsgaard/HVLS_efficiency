# HVLS_efficiency
In connection with my work as a test technician, where I was tasked with verifying HVLS air circulation fans, 
I discovered that it was very common for supplier/manufacturer information about their products to be exaggerated — in at least 90% of cases — regarding how much air,
their HVLS fan could move, some by up to 800%.

First, I created a spreadsheet that allowed me to quickly check whether the manufacturers' figures were plausible. 
If the air effect (output) was greater than the power consumption (input), 
It was clearly an exaggeration. Others had investigated the same tendency and concluded that an efficiency above 40–50% was improbable.

A spreadsheet is not that easy to share, and perhaps difficult for a layperson to get to grips with. 
That is why I made this App, where only 3 factors need to be entered (numbers that should be findable on a manufacturer's website), 
and it gives a clear answer as to whether the figures can be trusted.
