HVLS Fan Efficiency

A practical starting point for checking whether a high-volume, low-speed fan’s stated size, power, and airflow look credible.

This project contains both a standard browser calculator and an installable PWA version. Use the option that best fits your workflow, then review the project notes and license for context.
